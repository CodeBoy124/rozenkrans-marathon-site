## Project Structure (as observed)
- Posts stored in: `./src/content/posts/en/`, `./src/content/posts/nl/`
  - Files named with timestamp: e.g., `2026-05-08-the-website-is-finished.md`
- Post page templates: `./src/pages/en/post/[slug].astro` (and similar for other langs)
- Post rendering screen: `./src/screens/post/single.astro`
- Language locale handling: pages set locale, screens use translation i18n

## High-Level Implementation Strategy
Since Astro is static-site-only and this is frontend-only:
1. Add PDF path field extraction in post metadata (already defined as `pdf_path`)
2. Modify the rendered screen (`single.astro`) to insert the PDF viewer below the title
3. Create reusable Astro component (`src/components/PdfViewer.astro`) that renders an iframe

## Concrete Tasks (ordered implementation)

### Task 1: Create PDF Viewer Component
- File: `src/components/PdfViewer.astro`
- Props: `pdfPath` (string, e.g., "info.pdf")
- Renders: iframe with exact src matching pdfPath (no "public/" prefix)
- Example component:
  ```astro
  <iframe 
      src={props.pdfPath}
      width="100%" 
      height="600" 
      style="border: none; overflow: hidden;" 
      loading="lazy">
  </iframe>
  ```

  ```astro
  <BaseLayout ... />
  <div class="flex flex-col gap-inner text-center">
      <h2 class="text-3xl font-semibold">{post.data.title}</h2>
  ```
